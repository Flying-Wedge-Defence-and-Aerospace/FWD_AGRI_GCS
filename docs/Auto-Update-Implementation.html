Platforms: Linux (AppImage), Android (APK)  |  Qt 5.15.2  |  Date: August 2026

1. Overview

An in-app auto-update system was implemented for FWDAgriGCS that automatically checks for new releases on GitHub when the application starts. If a newer version is found, a dialog shows the version number and changelog. The user can download and install the update directly within the app without visiting any external website. Linux replaces the AppImage binary in-place and relaunches. Android downloads the APK and hands off to the system package installer via FileProvider. A release automation script (release.sh) handles version bumping, building, signing, and uploading to GitHub in a single command.

2. System Flow

App Startup → QTimer(3s delay) → checkForUpdates() → GitHub Releases API (/repos/.../releases/latest) → Parse JSON response → Compare semantic versions → If newer: find platform asset (.apk / .AppImage) → emit updateAvailable() signal → QML Update Dialog shown → User taps "Update Now" → downloadUpdate() → GitHub Asset API (with PAT auth + octet-stream header) → Save to temp directory → User taps "Restart Now" → installUpdate() [Linux] replace binary + chmod +x + relaunch [Android] FileProvider content:// URI + Intent → System Installer

4. Platform-Specific Implementation

Linux (AppImage)

  1. Get real binary path via $APPIMAGE env var
  2. Delete current binary: QFile::remove()
  3. Copy downloaded update: QFile::copy()
  4. Set executable permission: chmod +x
  5. Relaunch: QProcess::startDetached()
  6. Quit: QApplication::quit()

OpenSSL 1.1 libs bundled in AppDir for HTTPS connectivity.

Android (APK)

  1. Copy APK to app cache directory
  2. Get Activity via JNI: QtNative.activity()
  3. Get content:// URI: FileProvider.getUriForFile()
  4. Create ACTION_VIEW Intent with URI + APK MIME type
  5. Launch system package installer via startActivity()
  6. Quit: QApplication::quit()

AndroidX FileProvider required for Android 7+ content URIs.

5. Release Automation (release.sh)

Usage: ./release.sh <patch|minor|major|vX.Y.Z> [--linux-only|--android-only]

Steps: Check clean git state → Update APP_VERSION_STR in QGCCommon.pri → Patch AndroidManifest.xml versionName/versionCode → Build via qmake → Sign APK with debug keystore (apksigner) → Git commit + tag + push → Create GitHub release + upload assets.

versionCode formula: 66 * 10000000 + major * 1000000 + minor * 100000 + patch * 1000 (prefix 66 = arm64-v8a)
